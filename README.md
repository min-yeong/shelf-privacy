# Shelf 개인정보처리방침

시행일: 2026년 11월 5일

Shelf(이하 “앱”)는 사용자의 개인정보를 별도 서버로 수집하거나 전송하지 않습니다. 앱에서 생성하거나 선택한 정보는 사용자의 기기 안에서 처리됩니다.

## 1. 처리하는 정보

앱은 사용자가 직접 입력하거나 선택한 다음 정보를 기기 내부에 저장합니다.

- 제품명, 브랜드, 분류, 보관 장소, 수량
- 소비기한·유통기한·사용기한 등의 날짜
- 카메라로 촬영하거나 사진 보관함에서 선택한 제품 사진
- 제품별 알림 설정과 사용 완료·폐기 상태

이 정보는 앱 기능을 제공하기 위한 용도로만 사용되며 앱 운영자에게 전송되지 않습니다.

## 2. 사진과 문자 인식

사용자가 촬영하거나 선택한 사진은 제품 정보와 기한을 기록하고 사진 속 글자를 인식하는 데 사용됩니다. 문자 인식은 Google ML Kit의 기기 내 처리 기능을 이용합니다. 사진과 인식 결과를 앱 운영자의 서버로 전송하지 않습니다.

## 3. 알림

앱은 사용자가 선택한 기한과 시간에 알림을 보내기 위해 기기의 알림 권한을 사용합니다. 알림은 기기에서 예약되며 푸시 알림 서버나 광고 목적으로 사용되지 않습니다. 사용자는 앱 설정 또는 기기 설정에서 언제든 알림을 끌 수 있습니다.

## 4. 백업 파일

사용자가 백업 파일 만들기를 선택하면 등록 정보와 사진을 하나의 파일로 생성합니다. 파일의 저장·공유 위치는 사용자가 시스템 공유 화면에서 직접 선택합니다. 선택한 외부 앱이나 저장 서비스에서 이루어지는 처리는 해당 서비스의 개인정보처리방침을 따릅니다. Shelf 운영자는 백업 파일에 접근하지 않습니다.

## 5. 제3자 제공과 외부 전송

앱은 개인정보를 판매하거나 광고·분석 목적으로 제3자에게 제공하지 않습니다. 앱의 배포용 Android 버전은 인터넷 접근 권한을 사용하지 않습니다.

## 6. 보관 기간과 삭제

정보는 사용자가 앱에서 해당 물품을 삭제하거나 앱을 삭제할 때까지 기기 안에 보관됩니다. 백업 파일은 사용자가 선택한 위치에서 직접 삭제해야 합니다. 앱 운영자는 사용자의 기기나 백업 파일에 접근할 수 없으므로 별도로 복구하거나 삭제할 수 없습니다.

## 7. 아동의 개인정보

앱은 아동을 대상으로 설계되지 않았으며, 아동의 개인정보를 고의로 수집하지 않습니다.

## 8. 개인정보처리방침 변경

앱의 기능이나 관련 법령이 변경되면 이 방침을 수정할 수 있습니다. 중요한 변경 사항은 앱 배포 페이지 또는 이 문서에서 안내하며, 문서 상단의 시행일을 갱신합니다.
